# Lisens og rettigheter

## Kode

MIT-lisensen, se [LICENSE](../LICENSE). Du kan bruke, kopiere, endre, dele og
videreselge koden, også kommersielt, så lenge opphavsretts- og lisensnotisen beholdes.

## Entur-data

Reise- og sanntidsdata fra Entur er lisensiert under **NLOD 2.0**, ikke MIT.
Ved gjenbruk skal Entur krediteres, og endringer merkes. Se [NOTICE](../NOTICE)
og <https://data.norge.no/nlod/no/2.0>.

Testfixtures i `prototype/tests/fixtures/` er små Entur-eksempler og omfattes av
samme attribusjonskrav.

## Tredjeparter og varemerker

Entur og eventuelle leverandører som operatøren velger er navn på tredjeparter.
Navnene brukes for å beskrive faktiske integrasjoner. Dette prosjektet gir ikke
tredjeparter rett til å fremstå som offisiell operatør eller godkjenner
tredjepartsinstallasjoner.

MIT-lisensen gjelder kildekoden. Den gir ingen rett til å bruke Østfoldbussen-navnet,
logoen eller identiteten som offisiell tjeneste. Egne installasjoner må ikke fremstilles
som offisielle Østfoldbussen-installasjoner.

## Bidrag

Bidrag mottas under MIT. Send ikke inn data eller kode med uavklarte rettigheter.
